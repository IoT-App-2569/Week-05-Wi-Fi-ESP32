## 7. คำถามท้ายการทดลอง (Post-Lab Questions)

1. การกำหนดค่าในโครงสร้าง `wifi_scan_config_t` สำหรับสแกนเจาะจงเฉพาะช่องความถี่ (ข้อ 5.1.2) ช่วยลดเวลาในการสแกนเมื่อเทียบกับการสแกนทุกช่องความถี่ (ข้อ 5.1.1) อย่างไร และมีข้อจำกัดอย่างไร?

```
การสแกนแบบเจาะจง Channel ช่วยลดเวลาได้อย่างมาก (จาก 2493 ms เหลือเพียง 200 ms) เนื่องจาก ESP32 จะเข้าไปฟัง Beacon frame บนคลื่นความถี่ที่กำหนดเพียงช่องเดียว ไม่ต้องเสียเวลากระโดดสลับไปสแกนทีละช่องจนครบทั้ง 13 ช่อง 
ข้อจำกัด : ผู้ใช้งานจำเป็นต้องทราบช่องความถี่ (Channel) ที่แน่นอนของ Access Point เป้าหมายล่วงหน้า หาก AP ตัวนั้นมีการตั้งค่าเป็น Auto Channel และทำการสลับช่องความถี่หนีไปช่องอื่น ESP32 ก็จะสแกนไม่พบเครือข่ายนั้น
```

2. เมื่อสังเกตผล Forensic Log ในข้อ 5.1.4 (สแกนหา SSID ที่ไม่มีอยู่จริง) ฟังก์ชัน esp_wifi_scan_start(), esp_wifi_scan_get_ap_num() และ esp_wifi_scan_get_ap_records() ส่งคืนค่าอย่างไร?

```
- esp_wifi_scan_start() ส่งคืนค่า ESP_OK (0x0) แสดงว่าสั่งเริ่มการสแกนได้สำเร็จ ไม่มีข้อผิดพลาด และยังใช้เวลาสแกนตามปกติ (2498 ms)
- esp_wifi_scan_get_ap_num() ส่งคืนค่า ESP_OK (0x0) และให้ค่า ap_count = 0 
- esp_wifi_scan_get_ap_records() ในกรณีที่ ap_count เป็น 0 ระบบจะข้ามการเรียกใช้ฟังก์ชันนี้ไป หรือหากเรียกใช้ก็จะส่งค่า ESP_OK แต่จำนวน record ที่ได้กลับมาจะเป็น 0
```

3. ค่าระดับความแรงสัญญาณ (RSSI) ที่แสดงเป็นตัวเลขติดลบ (เช่น -45 dBm กับ -80 dBm) ค่าใดแสดงถึงสัญญาณที่มีความแรงและความเสถียรมากกว่ากัน?

```
ค่า -45 dBm แสดงถึงสัญญาณที่มีความแรงและความเสถียรมากกว่า เนื่องจากค่า RSSI เป็นตัวเลขติดลบ ยิ่งตัวเลขเข้าใกล้ 0 มากเท่าไหร่ ยิ่งแปลว่าสัญญาณมีความแรงมากเท่านั้น
```

4. เหตุใดการดึงค่า authmode (wifi_auth_mode_t) จากโครงสร้าง wifi_ap_record_t จึงมีความสำคัญต่อการเตรียมการในเฟสถัดไป (Authentication & Association Phase)?

```
มีความสำคัญมากเพราะ ESP32 จำเป็นต้องทราบว่า Access Point ที่เราจะเชื่อมต่อด้วยนั้น ใช้ระบบรักษาความปลอดภัยแบบใด (เช่น OPEN, WPA2_PSK, WPA3 เป็นต้น) เพื่อให้สามารถกำหนดค่าใน wifi_config_t ได้อย่างถูกต้อง หาก ESP32 ไม่ทราบ authmode หรือใช้วิธี Authentication ไม่ตรงกับที่ AP กำหนดไว้ จะทำให้การยืนยันตัวตนล้มเหลว (Auth Rejected) และไม่สามารถเชื่อมต่อ Wi-Fi ได้
```
