## 7. คำถามท้ายการทดลอง (Post-Lab Questions)

1. เหตุใดกระบวนการ **4-Way Handshake** จึงพิสูจน์ทราบรหัสผ่าน Wi-Fi ได้โดยไม่ต้องส่งรหัสผ่าน (Passphrase) ลอยไปในอากาศเลยแม้แต่แพ็กเกจเดียว?

```
เพราะกระบวนการนี้ใช้การเข้ารหัสทางคณิตศาสตร์แบบทิศทางเดียว ทั้งฝั่ง AP และ ESP32 จะนำรหัสผ่าน และชื่อ Wi-Fi  มาคำนวณเป็นคีย์หลัก ไว้ในเครื่องของตนเอง จากนั้นจะแลกเปลี่ยนเพียงค่าสุ่ม และ MAC Address เพื่อนำไปสร้างคีย์ชั่วคราว และยืนยันความถูกต้องด้วยรหัสรับรองข้อความ หากคำนวณ MIC ออกมาตรงกัน แสดงว่าทั้งสองฝั่งถือรหัสผ่านตัวเดียวกันอยู่ โดยไม่ต้องส่งรหัสผ่านจริงๆ ออกไปในอากาศเลย
```

2. อธิบายบทบาทและที่มาของคีย์ PMK (Pairwise Master Key) และ PTK (Pairwise Transient Key) ว่ามีความสัมพันธ์กันอย่างไรในการเข้ารหัสเฟรมข้อมูล?

```
- PMK  เป็นคีย์หลักที่ได้จากการนำรหัสผ่าน มาคำนวณร่วมกับชื่อ SSID โดย PMK จะถูกเก็บไว้เป็นความลับและไม่ถูกส่งผ่านอากาศเลย
- PTK เป็นคีย์ชั่วคราวที่ใช้สำหรับเข้ารหัสข้อมูล จริงๆ ในเซสชันนั้นๆ ซึ่ง PTK ถูกสร้างขึ้นมาจากการนำ PMK มาผสมกับค่าสุ่มของทั้งสองฝั่ง  และ MAC Address ของทั้ง AP และ Station
สรุปคือ PMK คือวัตถุดิบตั้งต้นที่ใช้เพื่อสร้าง PTK สำหรับนำไปเข้ารหัสข้อมูลต่อไป
```

3. เหตุใดเมื่อเราพิมพ์ Password ผิด (ข้อ 5.4.2) ESP32 จึงยังคงได้รับ Event WIFI_EVENT_STA_CONNECTED ก่อนที่จะเกิด Event WIFI_EVENT_STA_DISCONNECTED ตามมาในภายหลัง?

```
เนื่องจากในมาตรฐาน WPA2/WPA3 กระบวนการ Authentication เป็นเพียงการเปิดรับการเชื่อมต่อเบื้องต้นแบบ Open System ซึ่งไม่มีการตรวจสอบรหัสผ่าน และกระบวนการ Association ก็ทำหน้าที่เพียงยืนยันการเข้าร่วมกลุ่มเครือข่าย  เท่านั้น ทำให้เกิด Event `WIFI_EVENT_STA_CONNECTED` ขึ้น แต่การตรวจสอบรหัสผ่านที่แท้จริงจะอยู่ในกระบวนการ 4-Way Handshake เมื่อรหัสผ่านผิด Handshake จะล้มเหลว ทำให้ AP ตัดการเชื่อมต่อ และเกิด Event `WIFI_EVENT_STA_DISCONNECTED` ตามมา
```

4. หากเครือข่าย Wi-Fi ไม่มี DHCP Server (ไม่มีการแจก IP อัตโนมัติ) ผลการทดลองในข้อ 5.4.1 จะหยุดอยู่ที่ขั้นตอนใด และจะไม่เกิด Event ใดขึ้น?

```
ผลการทดลองจะผ่านกระบวนการ 4-Way Handshake ได้สำเร็จ และ ESP32 จะยังคงอยู่ในสถานะ WIFI_EVENT_STA_CONNECTED อย่างสมบูรณ์ แต่กระบวนการจะหยุดอยู่ที่เฟส 5 และจะไม่เกิด Event `IP_EVENT_STA_GOT_IP` ขึ้น เนื่องจากไม่มีเซิร์ฟเวอร์ใดตอบกลับหมายเลข IP มาให้
```
